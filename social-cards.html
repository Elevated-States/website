Elevated / Delevated — card generator

A brand-native social format: each state gets a card framed Elevated ↑ (progress) or Delevated ↓ (holding back / sliding), with its latest movement inside. Pulls straight from the atlas dataset — so it's ready to run one a day, with a weekly carousel. Pick a state (or hit random), tweak the tone, copy the caption. Screenshot the card at this size for posting; the automated version renders it at full 1080px.

How the automation works: a scheduled task runs each morning, picks the day's state (rotating, or the biggest mover), renders this card to a 1080px PNG, and writes the caption — dropping both into a folder (or straight to a scheduler like Buffer/Later). On Sundays it assembles the week's cards into a Week-in-Review carousel. Auto-posting to Instagram needs a Business account + the Meta API (or a scheduler); everything up to the post can be hands-off.
